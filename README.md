# 易经图谱 · yijing-atlas

周易揲蓍与卦象的可视化解释器。四十九策、十八变、本卦与之卦；经文、白话、王弼注与今解；筮法分步说明；以及二十八宿、二十四气、六十卦气同轴的星阵图。纯静态，离线可用，无构建、无后端。

在线版：<https://escap1ng.github.io/yijing-atlas/>

![筮仪台](demo/shot-initial.png?v=2)

## 功能

- **筮仪台**：分二、挂一、揲四、归奇逐步执行。每一步给出动作、数的变化、象征与校验；一变后余策必为 44 或 40，二变后 40 / 36 / 32，三变后 36 / 32 / 28 / 24。
- **成卦**：六爻自下而上，老变少不变，本卦与之卦并列；114 步完整回放。
- **经文**：通行本卦辞、大象、爻辞、小象，附现代白话、王弼注（四库本，可展开）、今解与术语注。今解按现代处境重述卦义，不作吉凶预测。
- **筮法**：卜与筮、大衍之数的由来，四营、三变、十八变的分步说明，附三变余策与爻值对照。
- **星阵**：二十八宿、二十四气、六十卦气三环同轴；拖动节气环可做拟合实验，实时显示 RMS 与等宽基线。

## 运行

在线版见页首链接；本地直接打开 `demo/index.html`，Chrome / Edge 下以 `file://` 打开即可，不需要安装依赖或启动服务。推送到 `main` 后，GitHub Actions 会把 `demo/` 发布到 Pages。

```

  index.html      入口
  style.css       样式
  core.js         揲蓍状态机与六十四卦表
  stars.js        星阵图
  app.js          界面与交互
  hextext.js      六十四卦经文、白话、王弼注
  modern.js       六十四卦今解
  shot.mjs        CDP 截图脚本（开发用）
research/
  前期调研.md      史源、概率、卦气、宿度与设计取舍
  verify_*.py     数值复核脚本
  build_*.py      经文/白话/王弼注数据构建脚本
```

## 数据与口径

- **经文**：通行本。异文与旧注未校。
- **白话**：取自 [chengjun/iching](https://github.com/chengjun/iching)（MIT），只取「白话文解释」，现代命理评断未收。白话为现代译文，不是经文原义。
- **王弼注**：四库本，公有领域。原本无句读，音义未收，异体字转简；只能作参考层，不宜当标准读本。
- **今解**：本项目自撰。按现代处境重述卦义，不是经文原义，也不作吉凶预测；用于理解，不代替原典。
- **二十八宿**：汉制距度（斗宿含 26¼），合计 365.25 古度。
- **揲蓍概率**：分堆均匀时，老阳 / 老阴 / 少阳 / 少阴约为 21.1% / 5.2% / 28.9% / 44.8%；挂扐理想值为 18.75 / 6.25 / 31.25 / 43.75。两者差异来自分堆边界，页面底部有说明。
- **星阵拟合**：最优 φ=76.5 时 RMS 4.74 古度，等宽基线 3.77。最优旋转仍差于等宽基线，说明二者没有隐藏对齐；共享的 365.25 才是可验证的部分。

## 范围

- 不做吉凶预测的因果承诺。工具只呈现「筮法产生什么结果」「传统怎么解释」，以及项目自撰的现代处境解读。
- 不选一家注疏冒充唯一答案；异说并列，注明出处。今解单独标注，不与经注混同。
- 当前版本：程颐、朱熹注未收，异文未校，卦气起点仅提供中孚/复两种锚点。
